# Command Clipboard

Quick access to frequently used commands with copy-to-clipboard, run in terminal, folders, pinning, and project/workspace/global scopes.

## Features

- **Save Commands** - Store frequently used terminal commands for quick access
- **Copy or Run** - One-click copy to clipboard or run directly in terminal
- **Search** - Quickly find any saved command across all scopes
- **Three Scopes:**
  - **Global** - Available across all workspaces
  - **Workspace** - Available only in the current workspace
  - **Project** - Scoped to a specific project folder
- **Pin Commands** - Pin your most-used commands for quick access
- **Organize with Folders** - Group related commands into folders
- **Duplicate Commands** - Quickly duplicate and modify existing commands

## Usage

1. Open the **Command Clipboard** panel from the activity bar (sidebar icon)
2. Click the **+** button to add a command or folder
3. Click any command to copy it to clipboard
4. Use the play button to run a command directly in the terminal
5. Use the search button to find commands across all scopes

### Keyboard Shortcut

- **Mac:** `Cmd+Shift+Q`
- **Windows/Linux:** `Ctrl+Shift+Q`

## Data Storage

Your commands are stored securely in VS Code's internal storage:
- **Global commands** persist across all workspaces
- **Workspace/Project commands** persist per workspace
- Data is **not lost** when updating the extension
